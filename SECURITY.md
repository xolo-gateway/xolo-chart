# Security policy

xolo-chart follows the [security policy of Xolo](https://github.com/xolo-gateway/xolo/blob/main/SECURITY.md).

Do not open a public issue for a vulnerability. Report it privately through
[GitHub private vulnerability reporting](https://github.com/xolo-gateway/xolo-chart/security/advisories/new).
A vulnerability of Xolo itself goes to
[Xolo's private reporting](https://github.com/xolo-gateway/xolo/security/advisories/new).
